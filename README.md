# Electric-Vehicle-EV-Market-Analysis-EDA
# ⚡ Electric Vehicle (EV) Market Analysis Project

An Exploratory Data Analysis (EDA) project built with Python to analyze consumer shifts, popular manufacturers, EV types, and market trends using data visualization libraries.

---

## 📌 Project Overview
This project was developed as part of an **Industrial Training Capstone** in **Data Visualization with Python**. The goal is to clean, analyze, and visualize real-world Electric Vehicle registration data to uncover key market adoption insights.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Processing:** Pandas
* **Visualization:** Matplotlib, Seaborn
* **Dataset Source:** Kaggle (`kagglehub`)

---

## 💡 Key Insights Uncovered
* **Market Leader:** Tesla leads the EV market share by a significant margin, followed by Nissan and Chevrolet.
* **Vehicle Technology:** Battery Electric Vehicles (BEV) account for the majority of market share compared to Plug-in Hybrid Electric Vehicles (PHEV).
* **Adoption Growth:** EV registrations experienced exponential growth starting after 2018.
* **Top Model:** Tesla Model 3 and Model Y are among the most registered EV models.
